# kmeans-kotatasikmalaya
Dashboard ini menyajikan hasil klasterisasi kecamatan di Kota Tasikmalaya menggunakan algoritma K-Means berdasarkan karakteristik kependudukan tahun 2023–2026. Hasil ditampilkan dalam bentuk ringkasan cluster, distribusi anggota, evaluasi jumlah cluster optimal, dan visualisasi peta.
